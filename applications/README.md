# Applications

Kubernetes definitions for applications deployed to the homelab belong here.

- `minio/`: internal S3-compatible object storage backed by Longhorn.
- `homepage/`: private dashboard for homelab services and cluster resources.
- `headlamp/`: read-only Kubernetes resource dashboard protected by NetBird SSO.
- `adguard-home/`: LAN-wide DNS filtering exposed through a Cilium L2 address.
- `vaultwarden/`: private Bitwarden-compatible password vault over NetBird.
- `loky-planner/`: hiking planner, media library, and mock publishing scheduler protected by NetBird SSO.
